# Untitled 2D Game

A 2D platformer I made in Godot. Collect coins, jump across platforms, and watch out for slimes.

## Play on Windows

Download the ZIP from [Releases](https://github.com/devcrogers14/Untitled-2D-Game-Release/releases/latest). Extract it and run **Untitled 2D Game.exe**.
